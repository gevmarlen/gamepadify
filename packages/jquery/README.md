# Gamepadify for jQuery

A small lifecycle adapter for [Gamepadify](https://github.com/gevmarlen/gamepadify).

```sh
npm install gamepadify gamepadify-jquery
```

Import `gamepadify/styles.css` in your application. Frameworks and the core are peer dependencies.

[Integration guide](https://github.com/gevmarlen/gamepadify#jquery) · [Examples](https://github.com/gevmarlen/gamepadify/tree/main/examples/jquery) · [Playground](https://gevmarlen.github.io/gamepadify/)
