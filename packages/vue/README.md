# Gamepadify for Vue

A small lifecycle adapter for [Gamepadify](https://github.com/gevmarlen/gamepadify).

```sh
npm install gamepadify gamepadify-vue
```

Import `gamepadify/styles.css` in your application. Frameworks and the core are peer dependencies.

[Integration guide](https://github.com/gevmarlen/gamepadify/blob/main/docs/api.md#vue) · [Examples](https://github.com/gevmarlen/gamepadify/tree/main/examples/vue) · [Playground](https://gevmarlen.github.io/gamepadify/)

MIT.

Optional smaller builds are available at `gamepadify-vue/core`, `/navigation` and `/hints`. The default import retains all features. See [build choices](https://github.com/gevmarlen/gamepadify/blob/main/docs/bundles.md) for matching stylesheets and examples.
