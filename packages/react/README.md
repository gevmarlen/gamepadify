# Gamepadify for React

A small lifecycle adapter for [Gamepadify](https://github.com/gevmarlen/gamepadify).

```sh
npm install gamepadify gamepadify-react
```

Import `gamepadify/styles.css` in your application. Frameworks and the core are peer dependencies.

[Integration guide](https://github.com/gevmarlen/gamepadify#react) · [Examples](https://github.com/gevmarlen/gamepadify/tree/main/examples/react) · [Playground](https://gevmarlen.github.io/gamepadify/)

MIT.

Optional smaller builds are available at `gamepadify-react/core`, `/navigation` and `/hints`. The default import retains all features. See [build choices](https://github.com/gevmarlen/gamepadify/blob/main/docs/bundles.md) for matching stylesheets and examples.
